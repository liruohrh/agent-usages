# 输出与格式

## 形态

文本报告是一棵树：**总 → 项目 → 会话**（`--subagent` / `--subagents` 再往下加范围层）。每个节点占两行——

```
Memolink
  I 889K · I/C 257.6M · I/T 258.5M · O 368K · R 558K · O/T 926K · T 259.4M · Q 1,027 · ¥22.0154
  查看草稿未解决问题
    I 258K · I/C 178.9M · I/T 179.1M · O 141K · R 342K · O/T 483K · T 179.6M · Q 488 · ¥8.1405
```

名称行**只有名字**，数字全在下一行。这样标题多长都不会把整行撑开，也就不需要表格的固定列宽——终端 80 格也能读。

## 指标字段

| 标签 | 含义 |
| --- | --- |
| `I` | 未命中缓存的输入 |
| `I/C` | 缓存命中输入（cache read） |
| `I/T` | 输入合计（未命中 + 命中 + 缓存写入） |
| `O` | 输出（非思考） |
| `R` | 输出（思考，reasoning） |
| `O/T` | 输出合计，即供应商报告的 completion 数 |
| `T` | Token 总计 |
| `Q` | 请求数 |
| `¥` | 费用（金额是十进制字符串，显示时去掉无意义的尾随零） |

四个桶**互不重叠**，所以 `I/T = I + I/C + 缓存写入`。**思考 token 是输出的一部分**：`O/T = O + R`，供应商把它报在 completion 计数里，只计一次。

**`R` 可能是 0**：推理 token 由 provider 上报，新版 DSH 默认的 `messages` 协议不带这个字段（见 [DSH 适配器](agents/dsh.md)），此时思考计 0，但 `O` 与 `O/T` 仍是真实的 completion 数。工具不会去估算。

## 折叠规则

同一个数字不在两处重复：

- 项目名下只有一个会话 → 不打印项目自己的指标行（项目名保留作分组标题）；
- 报告里只有一个项目 → 也不打印根部 `总` 的指标行；
- 会话没有子代理 → 不打印 `子代理` 行，`--subagent` 下也只留一行。

## 日期

- **窗口标题**：`标签 · 数据实际跨度`，按该窗口内第一条到最后一条请求算，因此半开的结束边界不会写成第二天。**同日才带小时**：`2026-07-01 8h~23h`；整段落在同一个小时里写成 `2026-07-01 8h ~`。同月只写一次月份（`2026-07-01 ~ 09`），跨月写全（`2026-07-01 ~ 2026-08-05`）。窗口内没有用量就不带跨度。
- **项目名后是开始日**，**会话与子代理名后是结束日**；与上一级显示的日期相同就省略，所以不会出现一列重复的日期。

## 时间窗口

默认只输出**总**（全部时间）。指定了才显示那一个范围：

| 参数 | 范围 |
| --- | --- |
| `--today` / `--week` / `--month` / `--year` | 今日 / 本周（周一开始）/ 本月 / 今年 |
| `--windows` | 一次输出 **总 / 今日 / 本周 / 本月 / 今年** 五段，每段内部与默认相同 |
| 位置参数或 `--from` / `--to` | 任意区间 |

位置参数也认 `today` / `week` / `month` / `year` 及其偏移（`week-1`、`month-1`、`today-7`）。

## 范围拆分

| 参数 | 效果 |
| --- | --- |
| （默认） | 子代理并入其父会话，不单独占行 |
| `--subagent` | 每个项目、每个会话拆成 **总 / 自身 / 子代理** 三行 |
| `--subagents` | 在 `--subagent` 之外，把每个子代理也逐个列出 |

```
Memolink
  总      I 889K · I/C 257.6M · I/T 258.5M · O 368K · R 558K · O/T 926K · T 259.4M · Q 1,027 · ¥22.0154
  自身    I 680K · I/C 252.3M · I/T 253.0M · O 274K · R 489K · O/T 763K · T 253.8M · Q 931 · ¥18.0882
  子代理  I 209K · I/C 5.27M · I/T 5.48M · O 93K · R 69K · O/T 163K · T 5.65M · Q 96 · ¥3.9273
```

恒等式在每一层都成立：**自身 + 子代理 = 总**（有测试断言）。会话标题后面会标出它覆盖的子代理数。

## 默认之外的附加块

默认都不显示，按需打开：

| 参数 | 内容 |
| --- | --- |
| `--cost` | `费用明细`（按计费项拆金额）与 `计价区间`（区间 × 峰谷的单价与金额） |
| `--models` | `模型明细` |

`费用明细` 的 token 是「按该项单价计费的 token」，有些来源下跨两个桶（`inputAndCacheWrite`），**相加会重复计数**，所以那张表只对金额求合计。单价放在 `计价区间` 里：跨峰谷计费的项没有单一单价。

## JSON

`--json` 与文本同源：单窗口时是原来的扁平结构，`--windows` 时顶层是 `sections: [{ label, … }]`。项目与会话都带 `own` / `spawned` / `nodeTotal` 三段，金额仍是十进制字符串。字段清单见 [README](../README.md)。
